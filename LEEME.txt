JUVEY AI V8 — versión web para Chrome

ARCHIVOS
- index.html: aplicación web
- manifest.json: configuración para instalar como PWA
- sw.js: caché offline básica

PROBAR EN EL MÓVIL
1. Descomprime el ZIP.
2. Para probar la interfaz, abre index.html en un navegador compatible.
3. Para instalarla como aplicación desde Chrome, publica los archivos en un sitio HTTPS, por ejemplo GitHub Pages.
4. Abre la URL publicada en Chrome → menú ⋮ → “Añadir a pantalla de inicio” o “Instalar aplicación”.

IMPORTANTE SOBRE GEMINI
- La clave API que estaba pegada en el código original debe revocarse y reemplazarse por una nueva.
- Esta demo solo mantiene la clave en la memoria de la pestaña; no la guarda en el almacenamiento local.
- No publiques una clave de API en el código de una web pública. Para una aplicación pública real, crea un backend privado que llame a Gemini.
- La conversación y progreso se guardan localmente en el navegador del dispositivo. Exporta copias si quieres conservarlos.
- Fortnite y MotoGP son módulos de demostración, no conectan a estadísticas en directo.

SEGURIDAD
La calculadora limita las expresiones a operaciones matemáticas básicas y no usa eval().
